## 🔧 CÓMO USAR

### Configuración de Bloques

```python
# Configuración en config.json
{
    "blocks": {
        "task_extractor_enabled": true,
        "task_min_priority": 3,
        "task_max_tasks": 10,
        "summary_enabled": true,
        "summary_max_sentences": 3,
        "keyword_extractor_enabled": true,
        "keyword_max_keywords": 10
    }
}
```

### Uso Programático

```python
from backend.blocks import BlockManager, TaskExtractorBlock
from backend.transcriber import Transcriber

# El transcriber ya configura los bloques automáticamente
transcriber = Transcriber(config_manager, ...)

# Los bloques se ejecutan automáticamente POST-transcripción
transcription = transcriber.transcribe_with_groq(audio_path)

# Obtener resultados de bloques
block_results = transcriber.get_block_stats()
```

### UI CustomTkinter

1. Abrir Audio2Text
2. Ir a tab "Configuración"
3. Activar/desactivar bloques con switches
4. Click en "Ver Estadísticas de Bloques"
5. Recarga automática al cambiar configuración
