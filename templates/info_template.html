🔑 Crear API Keys
1. Groq: console.groq.com/keys
2. NVIDIA: build.nvidia.com/
3. Configura tus API Keys en Configuración.
📝 Uso
  • Configura tu Hotkey (Default F12).
  • Presiona para grabar, suelta o presiona de nuevo para terminar.
  • La transcripción se copia al portapapeles automáticamente.
⚙️ Configuraciones
  • Servicio: Groq o NVIDIA
  • Rutas de guardado de audio/texto.
  • Idioma (ES/EN).
  • Modo (Mantener/Alternar).
